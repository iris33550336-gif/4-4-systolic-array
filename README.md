# 4×4 脉动阵列矩阵乘法器

本项目基于 Verilog HDL 实现了一个 4×4 脉动阵列矩阵乘法器，主要用于学习数字逻辑设计、乘加运算（MAC）以及脉动阵列的基本工作原理。

项目在原开源代码的基础上进行了复现和部分修改，并通过仿真观察数据传递和计算过程。

## 项目结构

- `block.v`：基本处理单元（PE），实现乘加累加运算及数据传递。
- `systolic_array.v`：4×4 脉动阵列顶层模块，由16个PE组成。
- `block_tb.v`：PE模块的独立仿真测试文件。
- `sys_array_tb.v`：脉动阵列整体仿真测试文件。

## 主要修改

在原项目基础上进行了以下调整：

- 使用命名端口方式整理模块连接。
- 增加了PE模块的独立测试文件。
- 修改了 `done` 完成信号的控制逻辑。
- 调整了仿真测试激励，并保存了相关波形图。

## 仿真

使用 Verilog 仿真工具进行功能测试，通过波形观察各模块的输入、输出以及计算过程。

目前主要完成了代码复现和基础仿真，后续计划进一步完善结果校验和时序控制。
